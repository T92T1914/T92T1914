The [input model](assets/profile-explainers-input.json) identifies the source
revision, paths and figure class. Four retained families are copied byte-for-byte
from pinned public figures. Their exact source paths and SHA256 values are in
`reused_artifacts`. Original numerical values, scales, typography and limits stay
attached. Re-rendering this collection performs no underlying project execution.

and the pinned [profile palette](assets/profile-figure-tokens.json). Lifecycle
spacing shows order, not elapsed time. Atlas labels independent fields without

packages or equate browser preview with native installation.

## Maintain the figures

The [rendering record](assets/profile-explainers.json) records input/output hashes,
actual dimensions, measured text geometry, reused-source identities and the font
files used for the six newly drawn compositions. Use an isolated environment and
genuine static Inter 4.1 Regular, SemiBold and Bold TTF faces:

```console
python -m pip install -r requirements-figures.txt
python scripts/render_project_explainers.py --font-dir /path/to/Inter/extras/ttf
python scripts/render_project_explainers.py --check
```

The renderer verifies font hashes, names and weights. New SVG labels are outlined
from those glyphs. Font binaries and machine paths are not distributed. Four
reused families remain committed artifacts: the renderer checks their pinned
hashes and leaves their bytes untouched. Regenerate those in their original
repositories using the linked source record, then review any changed provenance
and consumers explicitly. `--check` validates all forty committed PNG/SVG files
without plotting dependencies or executing any project.

The phone editions have their own layout or reuse the accepted narrow source.
Full-size routes remain available for fine numerical labels. The detailed MCTS
study remains collapsed. Ragged's first-order illustration is narrower than the
library's qualified derivative routes. MCTS reward is shaped reward, not win
probability. Solver's exact hit/stand example remains separate from its original
approximate split path. Freight's synthetic data remains separate from BTS.
Shipment's static page does not host its application. Calendar is a local
text-menu coursework program without an online calendar or AI service.

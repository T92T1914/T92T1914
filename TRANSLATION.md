# Read in another language

You can read the project explanations with your browser's page translation tool. Choose a language offered by your browser and keep the English source open when you copy a command or check a result.

This is help for reading the projects. It does not mean that every page has a maintained translation, that a translation has been reviewed by a fluent speaker, or that the programming interfaces change language.

## Start with your browser

Open the project page or its README, then use the browser's page translation control. Available languages and controls vary by browser, device and region.

| Browser | Official instructions |
| --- | --- |
| Chrome | [Translate pages](https://support.google.com/chrome/answer/173424?hl=en) |
| Edge | [Use Microsoft Translator](https://support.microsoft.com/en-us/edge/use-microsoft-translator-in-microsoft-edge-browser) |
| Firefox | [Firefox translations](https://support.mozilla.org/en-US/kb/website-translation) |
| Safari on Mac | [Translate a webpage](https://support.apple.com/guide/safari/translate-a-webpage-ibrw646b2ca2/mac) |

These links explain the browser controls. Opening this guide does not select a language, enable a service or install anything. Translation is a reader choice, and the browser or provider determines how it is performed.

## Keep the technical parts exact

Translate the explanations around the code. Keep program source, commands, options, package names, paths, API names, mathematical notation and saved data unchanged. A Python command remains a Python command, and a C++ or CUDA example keeps the same language and interface.

Where the project controls its HTML, [translation flags](https://www.w3.org/International/questions/qa-translate-flag) mark selected literal content for preservation. A browser or translation provider may handle those flags differently. GitHub controls the rendering of repository Markdown, so use the English source when copying executable examples.

Keep recorded values, units, dates, precision and source references intact. A translated explanation should not turn a saved experiment into a new measurement or remove a limitation. Compare important wording with the linked original evidence.

Image lettering does not become another language when the surrounding page is translated. Use the nearby explanation, image description or linked evidence table when one is available. The original figures remain unchanged.

If a translation changes a technical meaning, return to the English source and its linked evidence. Browser translation is a reading aid. It does not establish a new result, a new supported platform or a reviewed translation of the complete project.
